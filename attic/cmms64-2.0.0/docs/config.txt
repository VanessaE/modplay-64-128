# Config.txt - CMMS 64 v2.0.0

This file describes all of CMMS 64's configurable parameters.  By extension, 
this file also describes the format of the cmms-config file.  Items marked as
"bool" are single-byte flags where zero means "False" and any non-zero value
means "True".  All strings are padded with nulls.

Playlist/song title format
--------------------------

In the configuration dialog are options for setting the song title 
display format, and for setting the format of the entries in the 
playlist.  The following symbols are treated as variables:

%a	Artist
%f	Filename
%l	Length of sequence table
%m	Song length, minutes
%p	Full path to the file (excluding filename)
%s	Song length, seconds
%t	Song title

Any other characters are printed literally.

Example: you have a file named "foo.mod" in subdirectory "/some/path/" with a 
length of 12 minutes and 34 seconds, and a title field reading "bar".  The 
following string:

%t -*- %m:%s [%p%f]

Would render as:

bar -*- 12:34 [/some/path/foo.mod]

(Note the empty "artist" field - MOD files don't have such an attribute).
